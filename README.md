# Epic Pro Montage Packs | حزم مونتاج إيبك برو

حزمة مونتاج مجانية لفيديوهات تحديثات اللانشر والألعاب. كل الملفات مولّدة بالكود، حرة الاستخدام بلا حقوق.

## المحتوى
- `sfx/`: whoosh, whoosh_short, swipe, click, pop, ding, riser, impact (WAV)
- `lut/gaming_punch.cube`: تلوين بكونتراست وتشبع أعلى للقطات الألعاب (يشتغل في CapCut وPremiere وDaVinci وغيرها)
- `presets/`: ستايل النصوص وقواعد الزوم والقطع
- `INTRO_PLAN.md`: خطة مونتاج مقدمة 15 ثانية جاهزة

## الاستخدام
حمّل المستودع، استورد مجلد sfx وملف LUT في برنامجك، واتبع INTRO_PLAN.md.
